- **设计参考**: 新核云（xinheyun.com）、铱云（dinghuo123.com）

## 设计调研总结

### 图标风格
- 新核云：线性图标为主，配合渐变色装饰，整体科技感强
- 铱云：同样使用线性图标，蓝色系为主色调
- 行业通用趋势：stroke-based 线性图标 + currentColor（我们采用的方案）

### Hero区视觉
- 新核云：数据看板截图 + 粒子/渐变背景
- 铱云：抽象插图 + 渐变背景
- 建议方案：SVG自定义插图（仪表盘+手机mockup+连接线）

### 行业展示
- 新核云：模块化卡片 + 截图
- 铱云：行业分类标签 + 客户案例
- 建议方案：图标+行业名称卡片式布局
